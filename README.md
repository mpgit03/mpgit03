# 🚀 Featured Projects

## 📰 [CurioFeed](https://github.com/mpgit03/CurioFeed)

**[🌐 Live Demo](https://curio-feed-wine.vercel.app/)**

> Production-style personalized news aggregation and recommendation platform.

**Key Features**

- 📰 Automated RSS ingestion from multiple publishers
- 🔄 Asynchronous processing with **BullMQ workers**
- 🔁 Retry mechanisms and failure recovery
- 🤖 Gemini-powered article classification
- 🎯 Personalized feed ranking using topic affinity, recency, and source diversification
- 🔐 Authentication and pagination
- ⚡ Redis-backed background processing
- ☁️ Deployed on Vercel and Render

**Tech:** `Next.js` `Node.js` `Express.js` `PostgreSQL` `Prisma` `Redis` `BullMQ` `Clerk` `Gemini AI`
