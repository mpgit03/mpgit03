<h2 align="center">🚀 Featured Projects</h2>

<h3 align="center">📰 <a href="https://github.com/mpgit03/CurioFeed">CurioFeed</a></h3>

<div align="center">
  <a href="https://curio-feed-wine.vercel.app/">🌐 Live Demo</a>
  <p><strong>Personalized News Aggregation & Recommendation Platform</strong></p>
</div>

CurioFeed collects articles from multiple publishers, classifies content using AI, and builds personalized feeds based on user interests.

**Key Engineering Highlights**

- Built an RSS ingestion pipeline to collect articles from multiple publishers.
- Implemented asynchronous processing using **BullMQ, Redis, and background workers**.
- Integrated Gemini-powered article classification and topic-based personalization.
- Developed feed ranking using topic affinity, recency, and source diversification.
- Used PostgreSQL and Prisma to manage articles, topics, and user preferences.
- Implemented deduplication, retries, and recovery workflows.
- **Docker:** Extend the project with a containerized API, ingestion and classification workers, PostgreSQL, and Redis for reproducible local development.

**Tech:** `Next.js` `Node.js` `Express.js` `PostgreSQL` `Prisma` `Redis` `BullMQ` `Clerk` `Gemini`

<h3 align="center">🎵 <a href="https://github.com/mpgit03/Music-Manager-Saas">Music Manager SaaS</a></h3>

<div align="center">
  <a href="https://music-manager-saas.vercel.app/">🌐 Live Demo</a>
  <p><strong>Cross-Platform Playlist Transfer & Background Processing</strong></p>
</div>

A full-stack application that transfers playlists from Spotify to YouTube Music, with asynchronous conversion and recovery from external API failures.

**Key Engineering Highlights**

- Integrated Spotify and YouTube OAuth 2.0 flows.
- Built playlist conversion and metadata-based track matching.
- Used **BullMQ and Redis** for long-running conversion jobs.
- Implemented exponential backoff, partial-success handling, and selective retries for failed tracks.
- Separated the API server and background worker into independent processes.
- **Dockerized the local development environment with Docker Compose and five services:** Next.js frontend, Express API, MongoDB, Redis, and conversion worker.
- Configured container networking, environment variables, health checks, and service logs.
- Added reproducible commands to build, start, inspect, and stop the application.

**Tech:** `Next.js` `Node.js` `Express.js` `MongoDB` `Redis` `BullMQ` `Docker` `Docker Compose` `Spotify API` `YouTube Data API`
